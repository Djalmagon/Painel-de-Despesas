# Projeto - Painel de Despesas

O projeto vai usar Vite com Vanilla-TypeScript.

Apresentação visual do projeto:

Um card para adicionar uma nova despesa.
Lista de todas as despesas adicionadas, abaixo do card de "adicionar nova despesa".

Na lateral esquerda (sidebar) vamos ter as seguintes informçaões:

- Total de todas as despesas.
- O total para cada categoria.

Cada despesa:
- Id: String
- Título: String
- Valor: Number
- Categoria: Categoria

As categorias são fixas:
"Alimentos", "Transporte", "Lazer", "Saúde", "Outros"

O projeto vai usar HTML, CSS e TypeScript simples (vanilla).
Todos os eventos devem ser adicionado no TypeScript e não no HTML inline.

Todos os types devem estar no arquivo src/types.ts

Não vai haver persistência dos dados.

Utileze código simples e nde fácil manutenção.
